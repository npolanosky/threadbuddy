# ThreadBuddy

> ## Use it here: **https://npolanosky.github.io/threadbuddy/**
> Runs in any browser and installs as an offline app — no installation required.

ThreadBuddy is an open, cross-platform screw-thread dimension calculator for machining. It computes
external and internal thread dimensions, measurement over wires, tap drills, coating/polishing
allowances and more, across inch and metric thread families. All values are reconstructed from the
public engineering standards (ASME, ISO, DIN, BS, SAE).

It is a clean reimplementation inspired by the Windows program ME ThreadPal.

- Building, testing, and contributing: [DEVELOPMENT.md](DEVELOPMENT.md)
- Data sources, methodology, and legal basis: [PROVENANCE.md](PROVENANCE.md)

## Acknowledgement

ME ThreadPal was created by Michael Rainey of Close Tolerance Software, who sadly passed in 2022 (eventually resulting in ThreadPal becoming unobtainable). This project exists to keep that resource available and cross-platform. The original program, its help files, and its artwork
are not included here; ThreadBuddy is an independent reconstruction from public standards, heavily inspired by the functionality and UI layout of ThreadPal.
