# ThreadBuddy

> ## Use it here: **https://npolanosky.github.io/threadbuddy/**
> Runs in any browser and installs as an offline app — no installation required.

ThreadBuddy is an open, cross-platform screw-thread dimension calculator for machining. It computes
external and internal thread dimensions, measurement over wires, tap drills, coating/polishing
allowances and more, across inch and metric thread families. All values are reconstructed from the
public engineering standards (ASME, ISO, DIN, BS, SAE).

It is a clean-room reimplementation inspired by the Windows program ME ThreadPal.

- Building, testing, and contributing: [DEVELOPMENT.md](DEVELOPMENT.md)
